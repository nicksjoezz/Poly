**Title: [Showcase] I built a Weather Arbitrage Bot for Polymarket with a 24/7 Flask Dashboard and NASA Data Integration**

Hey everyone! I wanted to share a project I just finished—a Polymarket weather bot that automates the entire lifecycle of weather-based prediction trading.

**What does it do?**
The bot runs 24/7 in the background, scanning multiple global sources (NOAA, GDACS, etc.) for extreme weather alerts. It maps these locations to active Polymarket contracts and uses a custom "Edge" formula—incorporating NASA global temperature anomaly data—to decide when to strike.

**The Tech:**
*   **Engine:** Fully asynchronous Python backend using `aiohttp` for high-frequency data ingestion and the Polymarket SDK for execution.
*   **Filtering:** Implemented a sophisticated noise-filter (blacklist + regex) to ignore "sports weather" (like the Miami Heat or Carolina Hurricanes) and focus on actual climate events.
*   **Dashboard:** A Flask-based UI with real-time Socket.IO updates. It has a dedicated "Paper Mode" where you can set a starting balance and simulate performance against live market orders.
*   **Visuals:** Custom CSS animations for a weather-themed experience (clouds, rain effects).

**Use Case:**
Aside from pure arbitrage, it’s a great way to see how breaking news alerts can be programmatically linked to financial outcomes in decentralized markets.

I’m particularly proud of the temperature parsing logic—it handles °F and °C units and adjusts confidence based on global climate trends from NASA.

Happy to answer any questions about the Polymarket SDK or the data pipelines!
